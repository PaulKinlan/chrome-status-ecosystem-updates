# Iterator Includes

> **Report Week:** 2026-W35 | **Milestone:** Chrome 154 | **Category:** Enabled by default

## Overview

A TC39 proposal to allow the developer to ask whether an iterator yields a given value. Analogue to `Array.prototype.includes`.

## Ecosystem Status

- **Momentum:** High (180 points)
- **Standards Alignment:** Chromium-Led
- **Sentiment:** Positive
- **Executive Take:** The TC39 Iterator Includes proposal (`Iterator.prototype.includes`) has rapidly advanced to Stage 3, bringing the ergonomic simplicity of `Array.prototype.includes` with `SameValueZero` equality directly to lazy iterators. With Chrome shipping it in version 154 and both Safari Technology Preview and Firefox Nightly implementing support, the feature enjoys unanimous cross-engine alignment and is nearing full multi-browser interoperability.

### Recommendations
- Actionable Advice: Teams building for production can immediately leverage standard polyfills via `core-js` or `@es-shims/iterator-helpers`, while native usage can be adopted in progressive environments alongside modern Iterator Helpers.
- Shipping enabled by default in Chrome 154. Developers can begin adopting in production with progressive feature detection.
- Non-Chromium browser engines (WebKit/Gecko) have not formally signaled support. Wrap calls in conditional feature checks.
- No verified standalone runtime polyfill available; design progressive enhancement fallbacks for non-supporting browsers.
