# Animatable zoom

> **Report Week:** 2026-W37 | **Milestone:** Chrome 150 | **Category:** Enabled by default

## Overview

The CSS zoom property is animatable and interpolates as a <number>. Developers can transition and animate zoom to smoothly scale elements and their layout, complementing existing transform-based scaling.

## Ecosystem Status

- **Momentum:** Moderate (50 points)
- **Standards Alignment:** Chromium-Led
- **Sentiment:** Positive
- **Executive Take:** Animatable CSS zoom standardizes continuous number interpolation for the `zoom` property, enabling smooth CSS transitions and keyframe animations that resize both elements and their surrounding layout. Following the CSSWG resolution in CSS Viewport Module Level 1, Chromium enabled this by default in Chrome 150. The feature achieves rapid multi-engine alignment as WebKit and Gecko have actively matched continuous interpolation behavior.

### Recommendations
- Actionable Advice: Use animatable `zoom` primarily for layout-affecting scaling transitions or design-tool interfaces where surrounding document flow must adjust smoothly. For pure visual animations where reflow is unnecessary, continue using `transform: scale()` to avoid performance overhead from continuous layout recalculations.
- Shipping enabled by default in Chrome 150. Developers can begin adopting in production with progressive feature detection.
- Non-Chromium browser engines (WebKit/Gecko) have not formally signaled support. Wrap calls in conditional feature checks.
- No verified standalone runtime polyfill available; design progressive enhancement fallbacks for non-supporting browsers.
